# Atlanex AI Capsule JavaScript SDK

The SDK exposes the same implementation used by Atlanex itself.

```js
import {
  createCapsule,
  verifyCapsule,
  generateSigningKey,
  signCapsule,
  verifySignature,
  compareCapsules
} from "./sdk/javascript/index.mjs";

const capsule = await createCapsule({
  producer: {name: "My Agent"},
  incident: {kind: "tool-failure", title: "Unexpected tool result"},
  timeline: [],
  evidence: []
});

const key = await generateSigningKey();
const signed = await signCapsule(capsule, key.privateJwk);
const result = await verifySignature(signed, key.publicJwk);
console.log(result.ok);
```

## Trust

A Capsule may carry its own public key, which is enough to detect signature corruption and prove consistency with that key. To identify a known signer, verify with a public JWK obtained independently and compare the returned `keyId`.

Never publish the private JWK generated by `generateSigningKey()`.
